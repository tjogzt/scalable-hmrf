# H2d 分析：多种子规模曲线 + NMI/边界F1（审查后批次1）

## 目的（回应审查意见）
1. 修复"单实例"问题：5 个独立实例种子 × 5 规模档 × 每实例 3 个独立起点（rng seed 3/4/5），报均值±SD；
2. 补全立项承诺但缺失的指标：NMI + 边界 F1（严格边集：相邻域对集合 F1）；
3. 修复 S=750 的追溯问题（旧 h2 表内 0.9937 为"特定起点复核值"，与单起点政策混用）。

## 设置
K=8, d=20, 高斯发射（σ=0.5, μ_scale=2.0）, β=0.7, max_iter=300, tol=1e-4。
实例种子 (11,21,31,41,51)（真值 seed=iseed, 噪声 seed=iseed+1）；规模 S ∈ {100,250,500,750,1000}。
运行环境：anaconda Python 3.12 + numpy（同批次全部实测）。

## 关键发现

1. **≥250K：全实例稳定，主张成立**。250K 与 1M 档跨 5 实例、15 起点 ARI 均为 0.9934–0.9937（sd≤0.0001），"规模不引入精度崩塌"在多种子下成立。
2. **10K–62.5K 存在实例方差，机制已分解**（探针 probe_convergence.log）：
   - 慢收敛：S=100 实例21 的 r0 在 300 迭代上限内"看似崩坏"（0.88），放开到 3000 后 **378 迭代收敛至 0.9926**；S=250 实例51 的 r0 需 **2111 迭代** 才落定（且落定于 0.8253 的次优盆地）。
   - 次优盆地：同一实例不同起点可收敛到不同盆地（0.918 / 0.948 / 0.993 并存）。
   - 结论：小尺度方差 ≠ 规模崩塌，而是"慢收敛 + 盆地结构"；实践中需收敛监控 + 多起点，勿用固定小迭代上限。
3. **S=750 追溯修复（重要）**：实例11 在独立起点 seeds 3/4/5 下三次全部落于 **0.9627 稳定盆地**（其中 1 次 134 迭代收敛、2 次撞 300 上限）；而 seeds 6–11 六个额外起点 **全部在 13–16 迭代内到达 0.9937**。即：0.9937 并非不可达（6/9 起点可达），但旧 h2 脚注"2 起点复核值 0.9937"混用了不同起点政策与 betw-run 选择，**h2-scale 的表列口径已不可比，以本实验为准**。论文表述应为"9 起点中 6 个到达 0.9937、3 个陷入 0.963 盆地"。
4. **ELBO 选择在仿真中 15/15 全部选中最优起点**（ari_elbo ≡ ari_max，全部规模）——与真实数据（DLPFC，ELBO 选到 0.1302 劣解）形成鲜明对照。这强化了论文的开放问题：*ELBO 在良定仿真中可用、在真实数据中失效*，模型选择是真实数据的关键缺口（批次2 的留出预测似然实验直指此点）。
5. **边界 F1 随规模单调下降**（0.936→0.659）：严格边集定义下，规模越大边界相对越"细"且预测边界更难逐边重合。论文引用该指标时须附定义注记，并建议后续加"半径1容差"变体（批次2 可选）。
6. NMI 与 ARI 趋势一致（0.977–0.988）。

## 与 h2-scale 的关系
- h2d **取代** h2-scale 作为主表来源（统一 restarts=3/max_iter=300 政策 + 多种子 + 指标补全）；
- h2-scale 的 S=750 行（单起点 0.9627/复核 0.9937）与 S=1000 行（单起点 10.78s）均被 h2d 覆盖；旧文件保留为历史记录，勿再引用其数字。
