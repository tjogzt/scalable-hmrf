# H4d 分析：DLPFC 151673 指标补全（NMI + 边界F1）与标签留档（审查后批次1）

## 目的
1. 补全 DLPFC 的 NMI / 边界 F1（原 h4 只报 ARI）；
2. 量化 5 起点的完整分布（best/median/ELBO 选择）——回应"best-of-5 选择偏置"批评；
3. 留档 truth/oracle/各起点标签（供 fig4 出图与后续分析）。

## 方法
复跑 h4 最终配置（VST-HVG3000 + z-score + PCA50 + k-means++ 5 起点，β=0.7，max_iter=300，tol=1e-4；
oracle 参照：真标签均值 + 纯 MF，β 网格 {0.3,0.5,0.7,1.0} 取最优）。指标：ARI / NMI（算术平均归一化）/ 边界 F1（严格边集，六角邻接 21038 边）。数值与 h4_final 复现一致（init0=0.4557；ELBO 最优解 elbo=-242867.4 亦一致）。

- **Oracle 参照**：ARI 0.6215 / NMI 0.7185 / 边界F1 0.1846。

## 结论
1. **选择偏置量化**：best-of-5 = 0.456，median = 0.250，ELBO 选择 = 0.130。论文报 0.456 时必须并列 median；与文献区间（0.40–0.58）对照时应说明取 max。
2. **ELBO 失效再次确认**：最优 ELBO 解（init4）恰是第二差解——真实数据上 ELBO 选择的负结果从"两个任务族"扩到三个决策点（h4/h5b/h4d）。
3. **边界 F1 偏低是度量特性**：严格边集无容差，±1 spot 的边界偏移即近乎零重合（oracle 也仅 0.185）。h4d 保留该严格定义（可复现、无参数），后续建议补"半径1容差"变体供论文正文使用；当前数值仅适合作**方法间相对比较**。
4. NMI 与 ARI 排序一致（0.60 对应 0.456；0.32 对应 0.13），无反转。
